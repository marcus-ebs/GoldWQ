# GoldWQ
A lightweight World of Warcraft addon designed to help you quickly find weekly World Quests and activities that can reward raw gold.
GoldWQ
======
Tracks gold world quests, special assignments and weekly caches for the character you are logged into.

Commands
  /gwq            open / close the window
  /gwq options    options menu
  /gwq route      send a route through the gold world quests to TomTom
  /gwq list       list gold world quests in chat
  /gwq report     weekly report in chat
  /gwq minimap    show / hide the minimap button
